# 東京都心・最高気温モニター（実測 & 予測）

## 目的

東京都心の最高気温に関する実測データと予測データを可視化し、年ごとに指定した閾値（℃）以上の日数を比較するWebアプリケーション。実測値と予測値を同時に表示することで、気象トレンドを把握できます。

## 主な機能

- **インタラクティブな閾値調整**: スライダーで温度閾値（25℃～35℃）を自由に設定
- **実測・予測データの比較**: 実測データ（～2024年）と予測データ（2025年以降）を色分けして表示
- **年ごとの統計表示**: 選択した閾値以上の日数を年別で可視化

## ディレクトリ構成

```
tokyo_max_temp_app/
├── README.md              # このファイル
├── app.py                 # Streamlitアプリケーションのメインファイル

└── data/
```

## 使い方

### 1. 環境構築

#### 必要な環境
- Python 3.8以上

#### セットアップ手順

```bash
# リポジトリをクローン
git clone https://github.com/tasskkiu2/tokyo_max_temp_app.git
cd tokyo_max_temp_app

# 仮想環境を作成（推奨）
python -m venv venv

# 仮想環境を有効化
# Linux/Mac
source venv/bin/activate
# Windows
venv\Scripts\activate

# 依存パッケージをインストール
pip install -r requirements.txt
```

### 2. アプリケーションの実行

```bash
streamlit run app.py
```

ブラウザが自動的に開き、`http://localhost:8501` でアプリケーションが表示されます。

### 3. 使用方法

1. **温度閾値の設定**: 左側のスライダーで25℃～35℃の範囲で閾値を選択
2. **結果の表示**: グラフが自動的に更新され、選択した閾値以上の日数が年ごとに表示されます
   - **青色バー**: 実測値（2024年までのデータ）
   - **赤色バー**: 予測値（2025年以降の予測）

## ファイル詳細

### `app.py` - メインアプリケーション

Streamlitで構築されたメインアプリケーション。以下の処理を実行します：

1. **日本語フォント設定**: 「Noto Sans CJK JP」を使用
2. **データ読み込み**:
   - `data/max_data.csv`: 実測気温データを読み込み
   - `data/output.csv`: 予測気温データを読み込み
3. **データ処理**:
   - 日付をパース
   - 年度を抽出
   - 閾値以上の日数をカウント
4. **可視化**: Altairを使用してインタラクティブなバーチャートを表示

### `max_temp.ipynb` - Jupyter Notebook

データ分析と予測モデルの構築・検証用Notebook（99.7%のリポジトリ構成）。以下を含みます：

- データの統計分析
- 気象トレンドの分析
- 予測モデルの構築（Prophet等）
- 予測結果の検証とvisual化

### `data/max_data.csv` - 実測気温データ

東京都心の歴史的な最高気温データ。形式：
```
年月日, 最高気温(℃)
2000-01-01, 15.5
2000-01-02, 16.2
...
```

### `data/output.csv` - 予測気温データ

気温予測モデルの出力結果。形式：
```
ds, yhat
2025-01-01, 18.3
2025-01-02, 19.1
...
```

## トラブルシューティング

### 日本語が文字化けする場合

`app.py` の以下の行で日本語フォントを指定していますが、フォントがない場合は別のフォントに変更してください：

```python
plt.rcParams['font.family'] = 'Noto Sans CJK JP'
```

### CSVファイルが見つからない場合

`data/` ディレクトリに以下のファイルが存在することを確認してください：
- `max_data.csv`
- `output.csv`
